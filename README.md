# dsh-deepseek-usage-ru

Панель расхода и баланса DeepSeek для DeepSeek Harness — **русская сборка**.
Форк проекта [sdiwenchen-lang/DeepSeek-Usage](https://github.com/sdiwenchen-lang/DeepSeek-Usage) (MIT).

## Что показывает

- **Баланс аккаунта** — из официального личного кабинета DeepSeek, по всем кошелькам (CNY и USD).
- **Официальный счёт**: расход, запросы, токены; календарь по дням, графики по моделям и сессиям, выбор периода.
- **Карточка в левой панели**: баланс, воркспейс последнего чата, курс ЦБ РФ.
- **Чип под полем ввода**: токены и стоимость текущей сессии.
- **Дневной лимит** с остановкой вызовов при превышении.

## Установка

**Из магазина DSH.** Добавьте адрес индекса этого репозитория в источники плагинов:

```
https://raw.githubusercontent.com/chukhlebovv-debug/dsh-deepseek-usage-ru/main/index.json
```

Настройки → Плагины → источники → добавить адрес; затем вкладка Discover → `dsh-deepseek-usage-ru` → установить.
Перезапустить DeepSeek Harness.

**Вручную.** Скачайте репозиторий и запустите:

```
powershell -ExecutionPolicy Bypass -File .\install.ps1 -ReplaceStore
```

`-ReplaceStore` убирает магазинную версию `deepseek-usage`: у неё те же маршруты, две панели конфликтуют.
Затем полностью перезапустить DeepSeek Harness.

## Данные и приватность

Внешних адресов два: `platform.deepseek.com` (баланс и счёт, по вашему уже выполненному входу в DSH —
токен на диск не пишется) и `cbr.ru` (курс валют). Больше никуда плагин не обращается.
